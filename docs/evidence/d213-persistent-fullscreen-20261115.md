Phone input uses the entire latched video rectangle. Settings remain accessible from the disconnected launcher's Home/Settings flow or owner commands; no hidden gesture is introduced.

Language, wireless discovery, microphone mute and the applied display mode are stored in `/data/carplay-ui.bin`. The application serializes access with an RT-Thread mutex, validates a fixed-size versioned/checksummed record, flushes a temporary file before promotion and supports a replacement backup. Invalid/missing records use defaults; failed saves are reported. Language is restored before the first launcher frame; the other settings are restored before the connection worker starts. Manual transport selection remains respected. The preference file contains no pairing secrets, but firmware backup/restore must include it to retain choices if `/data` is replaced. This is a normal-reboot persistence implementation, not verified power-cut durability.

A new LIVE transition closes read-only/settings pages and resumes the selected mode. A temporarily unavailable status snapshot does not reset the transition latch. Reconfiguration and failed connection stages do not count as success. Existing fusion sessions may still open settings deliberately.
